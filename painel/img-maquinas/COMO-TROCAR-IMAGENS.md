# Como colocar as fotos reais das máquinas

O material visual A3 (`apresentacao-walton-visual.html`) já está preparado para
receber fotos reais das máquinas. Cada lâmina tem um **slot de foto**:

- **Se o arquivo da foto existir** nesta pasta → a foto cobre a ilustração automaticamente.
- **Se não existir** → a ilustração técnica (desenho) continua aparecendo. Nada quebra.

## Passo a passo

1. Consiga a foto de cada máquina (do fornecedor, do catálogo, da feira, etc.).
2. Salve nesta pasta (`painel/img-maquinas/`) com **exatamente** o nome abaixo,
   em `.jpg`. Formato ideal: horizontal, boa resolução (ex.: 1200×800 px).
3. Gere o PDF de novo (botão "⤓ Exportar PDF" no HTML, ou o script de render).
   As fotos entram no lugar das ilustrações sozinhas.

Não precisa colocar todas de uma vez — cada foto que você adicionar já entra;
as que faltarem continuam com a ilustração. Pode misturar foto e desenho sem problema.

> Observação: o **dossiê técnico A4** usa ícones pequenos (glifos), não fotos —
> por isso ele não precisa de imagens. As fotos são só para o material visual A3.
