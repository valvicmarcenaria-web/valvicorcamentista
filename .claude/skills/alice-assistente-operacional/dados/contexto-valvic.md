## Glossário de fábrica

A Karla não precisa saber fazer — precisa saber o que a palavra significa para não comprar
errado nem repassar demanda torta.

| Termo | O que é |
|---|---|
| **MDF / MDP** | Os dois painéis de madeira usados. MDF é mais denso e aceita usinagem; MDP é mais barato e usado em caixaria |
| **Chapa** | A placa inteira, normalmente 2750 × 1840 mm. É o maior custo de material |
| **Espessura** | 6, 15, 18 e 25 mm são as comuns. Pedir espessura errada inutiliza a chapa |
| **Fita de borda** | A tira que acaba o canto da peça. **A cor tem de bater com a chapa** — erro clássico de compra |
| **Filetagem / colagem de fita** | A etapa em que a fita é colada na borda |
| **Plano de corte** | O desenho de como as peças saem da chapa, feito na programação |
| **Sistema 32** | O padrão de furação a cada 32 mm que permite montar e regular prateleira e dobradiça |
| **Corrediça** | O trilho da gaveta. Telescópica (aparente) ou oculta com amortecedor (mais nobre) |
| **Dobradiça / copo** | A dobradiça da porta; "copo" é o furo redondo onde ela encaixa |
| **Articulador** | O pistão que segura a porta que abre para cima |
| **Módulo** | Uma caixa do móvel. Móvel grande é feito de vários módulos |
| **Caixaria** | O conjunto das caixas, sem portas e frentes |
| **Frentes** | Portas e frentes de gaveta — o que aparece |
| **RT** | Comissão paga a arquiteta ou decoradora que indica o projeto. **Assunto comercial → Jonathan** |
| **Carreto** | O transporte do móvel da fábrica para a obra |

## O fluxo de uma obra, do começo ao fim

```
venda → medição → projeto executivo → plano de corte → corte (CNC) →
filetagem → furação → montagem em fábrica → carga → montagem em obra →
conferência → entrega → pós-entrega
```

Saber **em que etapa cada obra está** é metade do trabalho de interface com a produção.
