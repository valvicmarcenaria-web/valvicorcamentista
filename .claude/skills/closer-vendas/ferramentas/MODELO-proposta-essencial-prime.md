# MODELO de Proposta — "Essencial Prime" (padrão Vitor, layout claro)

> **Este é o modelo de proposta de referência da Valvic** (jul/2026). Sempre que for
> montar uma proposta nova, **clone este modelo**. Instância canônica:
> **`proposta-monica-premium.html`** (Mônica Cristina) — abra para ver o layout pronto.
> Origem do layout: proposta Jairo Samuel (claro/sofisticado), evoluída para 2 cenários.

## Quando usar
- Projeto com **acabamento premium** (laca, ferragem alemã, sistemas importados).
- Sempre que fizer sentido oferecer **duas linhas de garantia** (upsell natural).
- Cliente que valoriza durabilidade, tecnologia e execução fina.

## Identidade do layout (claro, não o escuro antigo)
- Fundo creme (`#FBFAF7`), tipografia **Cormorant Garamond** (display) + **Inter** (texto),
  dourado `#B8924F`. Caixas **escuras** só nos pontos de ênfase. Moldura fina na capa.
- **794×1123px por página** (A4). PDF via WeasyPrint (CSS já preparado) ou Chrome→Imprimir.

## Estrutura de 7 páginas (ordem)
1. **Capa** — wordmark `valvic.` + hero (imagem do projeto) + "Proposta especial para /
   [Cliente]" + subtítulo (ambientes · arquiteto) + data/nº/validade.
2. **Quem vai executar** — "O projeto é da [arquiteta]. A execução é nossa." + caixa de
   parceria + **caixa escura** "não vendemos móveis de catálogo, vendemos execução".
   *(anti-empeno + puxador/laca + equipe própria entram aqui.)*
3. **Ambiente a ambiente** — grid 2×2 de **imagens 3D do projeto** + legendas. Banda sutil
   dourada destacando **"LED por nossa conta — fornecido e instalado"** (praticidade).
4. **Acabamento assinatura** — puxador abaulado + **laca**: explica que **a fita não
   acompanha a curva do abaulado, só a laca entrega**; 4 etapas; **ilustração SVG do
   laqueamento**; caixa escura com a **promessa de AMOSTRA física na aprovação**.
5. **Escolha o nível de engenharia** — 2 cards de ferragem (**Essencial** claro / **Prime**
   escuro) + **cards expressivos dos sistemas de porta com ícone** (item premium recebe
   um **detalhe distinto**: selo "★ origem italiana", borda/chips dourados) + caixa
   pós-venda escura.
6. **Investimento** — tabela **duas colunas (Essencial / Prime)** por ambiente + total
   dourado; cards prazo/validade/garantia; condições de pagamento **com o à vista em
   card de destaque estratégico** ("melhor condição", 8%, sem gritar).
7. **Como conduzimos** — 5 etapas (a etapa 02 = **amostra do acabamento + aprovação**) +
   caixa escura "por que a Valvic".

## As DUAS LINHAS (o coração do modelo)
Projeto, acabamentos e execução **idênticos**; muda só a **ferragem** e, com ela, a garantia:

| | **Essencial** | **Essencial Prime** |
|---|---|---|
| Dobradiça | Hardt | **Hettich Sensys (alemã)** |
| Corrediça | Hardt / Hettich Quadro | **Hettich Actro** (100.000 ciclos, ajuste 3D, gel) |
| Porta de correr | **Rometal RO82 top** (nacional) | **Siforma** (origem italiana — + suave/resistente/durável) |
| Garantia | **5 anos** | **10 anos** |

> **Sempre um detalhe diferente para itens diferenciados:** o item premium (Prime/Siforma)
> ganha tratamento visual distinto (selo, dourado, borda) — nunca igual ao item padrão.

## Regras de preço (Lavinia → Vitor)
- MC pode ser **por ambiente**; **RT = repasse por cima** (fora do divisor).
- Prime = Essencial + upgrade de ferragem, **reprecificado na mesma MC** do ambiente.
- **À vista = −8%** (economia da taxa de cartão) — sempre mostrar como vantagem.
