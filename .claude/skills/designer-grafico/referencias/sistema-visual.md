# Sistema visual Valvic — direção de Stefan

A identidade Valvic hoje é **inferida das propostas** (ver
`closer-vendas/referencias/identidade-marca.md`). Este documento eleva isso para
direção real e justificada. Cada escolha tem um porquê de negócio.

## Diagnóstico do estado atual

O dourado mostarda + serifa + faixas funciona, mas tende ao "premium genérico de
marcenaria". O salto de patamar (rumo a Ornare/Florense) exige:
- **Mais respiro** (espaço negativo é sinal de confiança e alto padrão).
- **A madeira como protagonista**, não a faixa dourada.
- **Dourado como acento pontual** (latão envelhecido), não como bloco de cor.
- **Fotografia de luz dirigida** ocupando grandes áreas.

## Paletas por território

### Signature (premium / Blum)
| Uso | Cor |
|---|---|
| Base | Preto fosco `#1C1C1A` / grafite `#2B2B28` |
| Fundo nobre | Off-white quente `#F4F0E8` |
| Acento | Latão envelhecido `#A8895C` (não dourado brilhante) |
| Texto sobre escuro | Off-white `#EDE8DD` |

Editorial, dramático. A madeira e a luz fazem o trabalho. Dourado quase ausente —
sofisticação é contenção.

### Excellence (médio-alto / Hettich)
| Uso | Cor |
|---|---|
| Fundo | Areia clara `#F2ECDE` |
| Texto | Grafite `#2B2B28` |
| Acento | Dourado sóbrio `#C49A4A` |
| Madeira ref. | Tons naturais (freijó, carvalho) das fotos |

Equilíbrio entre aspiração e clareza. Acolhe sem intimidar.

### Essencial (base / Hardt)
| Uso | Cor |
|---|---|
| Fundo | Branco quente `#FBF8F2` |
| Texto | Grafite `#2B2B28` |
| Acento | Terracota suave `#B07A56` + dourado discreto |

Claro, organizado, confiável. Premium sem peso. Reduz o medo do cliente inseguro.

## Tipografia

| Função | Fontes (ordem de preferência) | Por quê |
|---|---|---|
| Display / nome do cliente | Canela, Ogg, Playfair Display, Cormorant | Serifa de alto contraste = editorial, grife |
| Títulos de seção | Söhne, Neue Haas, Inter (medium, tracking aberto) | Sem-serifa limpa = precisão, modernidade |
| Corpo | Inter, Barlow, Söhne | Legibilidade impecável em tela e impresso |
| Detalhe técnico (ferragem, espessura) | Space Mono, JetBrains Mono | Mono = engenharia, autoridade técnica |

Disponíveis no Google Fonts (exceto Canela/Ogg/Söhne/Neue Haas, que são pagas —
fallback: Playfair Display + Inter). Nunca decorativa barata.

## Grafismos

- **Sparkle de 4 pontas** (estrela Valvic): manter, mas refinar — fino, pontual,
  como assinatura, não como enfeite repetido.
- **Filete/linha de latão:** divisor sutil entre seções (1px, cor de acento).
- **Cava/sombra de encaixe:** referência ao detalhe da marcenaria (puxador em
  cava) pode virar elemento gráfico recorrente — assinatura visual única.

## Regras de layout

- Margens generosas (mín. 8% da página em A4).
- Uma ideia por bloco; nunca competir por atenção.
- Foto sangra (bleed) quando é o herói; respira com moldura quando é apoio.
- Hierarquia: 1 título dominante, 1 subtítulo, corpo. Sem 5 pesos brigando.
