# Modelos & Templates da Helena

Estruturas prontas para as saídas mais comuns. Copiar, preencher, usar. Objetivo:
padronizar sem engessar. Documentos "de gráfica" (apresentações, relatórios) seguem o
padrão visual Valvic (ver `gestao-documentos.md`); os de baixo são de **gestão do dia a dia**.

---

## 1 · Ata de reunião (curta)
```
ATA — <tipo de reunião> · <data>
Presentes: <nomes>
Objetivo (1 frase): <...>

Decisões:
- <o quê> — porque <...> (decidiu: <quem>)

Tarefas (dono · prazo):
- [ ] <tarefa> — <dono> — <prazo>

Travas / a destravar:
- <...>

Próxima reunião: <data> · foco: <...>
```

## 2 · Tarefa (padrão CENTRAL)
```
- [ ] <verbo + resultado esperado> | dono: <quem> | prazo: <data> | prioridade: <alta/média/baixa>
      contexto: <por que importa / de onde veio> | follow-up: <quando cobrar>
```

## 3 · Decisão registrada
```
| <data> | <o que foi decidido> | <por quê> | <quem decidiu> |
```

## 4 · Plano de ação (meta → degraus)
```
OBJETIVO (trimestre): <qualitativo, inspirador>
Resultados-chave (numéricos):
1. <KR mensurável>   2. <KR>   3. <KR>

Degraus (o que fazer, em ordem):
| # | Passo | Dono | Prazo | Sinal de "pronto" |
|---|-------|------|-------|-------------------|

Riscos / dependências: <...>
Quem é consultado / aprovador: <...>
```

## 5 · Briefing de documento (antes de produzir)
```
Documento: <nome>
Para quem: <interno / cliente / investidor>
Que decisão apoia: <...>
Mensagem principal (1 frase): <...>
Tom: <...>   Formato: <A4 leitura / A3 impressão / slide>
Sigilo: <restrito / interno / externo>
Prazo: <...>
```

## 6 · Follow-up (cobrança elegante)
```
Assunto: <tarefa> — retomando
Combinamos <o quê> até <data>. Como está? Precisa de algo destravado da minha parte?
Se mudou a prioridade, me avisa que reorganizo.
```

## 7 · Roteamento para especialista (handoff com contexto pronto)
```
Para: <Rodrigo / Lavinia / Closer / Deivson>
Contexto: <situação em 2–3 linhas>
O que preciso: <pergunta/decisão específica>
Prazo: <...>   Materiais anexos: <links/arquivos>
```

## 8 · Preparação de reunião (pré-pauta)
```
Reunião: <...> · <data> · <duração alvo>
Objetivo: <1 frase>
Pauta (máx. 4 itens, do mais importante ao menos):
1. <...>  2. <...>
Decisões que preciso sair com elas: <...>
Números/documentos a ter em mãos: <...>
```
