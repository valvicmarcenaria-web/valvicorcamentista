# Checklist de FECHAMENTO — rodar ANTES de entregar qualquer orçamento

> **Premissa (SKILL.md):** nenhum orçamento sai sem passar por este portão. Marcar cada
> item. Se algum falhar, **não entregar** — corrigir ou perguntar/alinhar. Construído com
> as lições do fundador (não repetir os erros).

## Material
- [ ] **Chapa INTEIRA.** Quantitativo de chapa é número de **PROJETO**, não de móvel:
      somar área por cor × espessura do projeto todo → ÷ área útil (15/18mm ≈ 4,17 m² ·
      6mm ≈ 2,80 m²) → **arredondar PRA CIMA** = chapas inteiras compradas. **Nunca fração**
      (ninguém compra 0,18 de chapa). A sobra é real (plano de corte alimenta outros móveis).
      A divisão por ambiente é só **alocação de PREÇO**, não compra.
      - **Nuance (confirmado pelo fundador):** isso vale para **CHAPA (MDF)**. Itens vendidos
        por **m²** (vidro, laca, espelho) ou por **metro** (fita, LED, perfil) **podem ser
        decimais** (ex.: vidro 0,6 m²). Só a chapa é inteira.
- [ ] **Ler o descritivo até o fim** — espessura, código, fixação. Incoerência mata caixa
      (ex.: "MDF Itapuã 1,3mm" = **laminado**, não chapa de MDF).
- [ ] **Acabamento/cor certos** mapeados na base (não inventar preço).

## Medição
- [ ] **Medido, NÃO chutado.** Cota do projeto ou **escalímetro** (referência de móvel
      conhecido). Na dúvida: **pergunta e alinha** — nunca "erra pra cima".
- [ ] **Sem referência (vidro, puxador especial) → especificar + PERGUNTAR ao fornecedor.**

## Ferragens / itens específicos
- [ ] **Puxador/ferragem como o PROJETO pede** (ex.: Livorno de embutir, cava 45°), não o genérico.
- [ ] **Painel com portas = 3 partes:** portas + painel + sistemas (RO82/oculta/tip-on).
- [ ] **Itens pontuais/sob encomenda → +30%** SOMENTE quando o fundador pontuar (não automático).
- [ ] **LED da marcenaria** incluído por padrão; **logística dedicada** onde houver terceirizado/laser/vidro.

## Margem / estratégia
- [ ] **Curva** → +15% material, +5% MC na peça curva.
- [ ] **Terceirizado/marmoraria/“existente” FORA** do nosso escopo (confirmar).
- [ ] **Encargos certos** (parceiro RT → vend 0 ~30% · venda direta ~26%).
- [ ] **MC alvo aplicada** e **validada no app** (importar JSON, conferir MC%).
