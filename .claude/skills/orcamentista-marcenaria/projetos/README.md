# Projetos resolvidos (exemplos de treino)

Esta pasta guarda projetos reais já orçados pela Valvic, usados como exemplos
de referência da metodologia do orçamentista.

## Como usar

- Cada projeto é um arquivo `.md` seguindo `TEMPLATE.md`.
- Nomeie por cliente/ambiente, ex.: `2026-cozinha-fulano.md`.
- Ao orçar algo semelhante, consulte o projeto análogo como referência de
  decisões (decomposição, quantidades, critérios).
